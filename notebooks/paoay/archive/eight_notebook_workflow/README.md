# Preserved eight-notebook workflow

Historical entry points before the five-notebook migration. Source and notebook metadata are retained; execution outputs are omitted from Git to keep local paths and generated data private. Executed originals remain in ignored `.notebook_backups/` locally. `inventory.json` records checksums of these shareable snapshots. Historical artifacts remain in their original data folders.

These notebooks are for historical inspection; running them can update live stage pointers. Use [the active workflow guide](../../../../docs/paoay_workflow.md) for the current sequence.
